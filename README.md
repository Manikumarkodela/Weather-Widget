# Weather Widget 🌤️

This is my first React project and my first project uploaded to GitHub.

The Weather Widget is a simple and responsive web application built using **React** and **Vite**. It allows users to search for any city and view real-time weather information through a weather API.

## Features
- 🌍 Search weather by city
- 🌡️ Display temperature and weather conditions
- 💧 Show humidity and wind speed
- ⚡ Fast performance with Vite
- 📱 Responsive and clean user interface

## Technologies Used
- React
- Vite
- JavaScript
- HTML
- CSS
- Weather API
